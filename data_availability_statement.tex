\section*{Data availability statement}
The source code and supporting materials for the Leaf-on CHM Generator framework, including the deep learning model architectures and the inference pipeline, are openly available in Zenodo at \url{https://doi.org/10.5281/zenodo.19876738} and in the corresponding public GitHub repository at \url{https://github.com/hunsoosong/leaf-on-chm-generator} \cite{kim2026leafonchmdata}. \textcolor{blue}{The trained Pix2Pix and U-Net model weights used in this study are openly available through GitHub Release v1.1.0 at \url{https://github.com/hunsoosong/leaf-on-chm-generator/releases/tag/v1.1.0}. The source code, supporting materials, and trained model weights are publicly accessible without login or access approval and are provided under the Creative Commons Attribution 4.0 International License (CC BY 4.0).} The deployed web application, which provides access to the pre-trained models for \textcolor{blue}{on-demand leaf-on CHM generation from user-selected areas with available input data}, is available at \url{https://log.d2s.org}. The leaf-off airborne LiDAR data used in this study are publicly available from the U.S. Geological Survey's 3D Elevation Program (3DEP) \cite{3DEP}. The leaf-on airborne LiDAR reference data are publicly available from the National Ecological Observatory Network (NEON) \cite{NEON}. The multispectral imagery used in this study is publicly available through the USDA National Agriculture Imagery Program (NAIP) \cite{NAIP}.

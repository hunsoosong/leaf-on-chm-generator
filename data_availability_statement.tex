\section*{Data availability statement}
The source code of the interactive Leaf-on CHM Generator web application, including the deep learning model architectures (Pix2Pix and U-Net) and the inference pipeline, is openly available in Zenodo at https://doi.org/10.5281/zenodo.xxxxxxx \cite{kim2026leafonchmcode} and at https://github.com/hunsoosong/leaf-on-chm-generator. The deployed web application, which provides access to the pre-trained models for on-demand leaf-on canopy height model generation across the United States, is available at https://log.d2s.org. Trained model weights are accessible through the web application, and are additionally available from the corresponding author upon reasonable request for academic, non-commercial reproducibility purposes. The leaf-off airborne LiDAR data used in this study are publicly available from the U.S. Geological Survey's 3D Elevation Program (3DEP) \cite{3DEP}. The leaf-on airborne LiDAR reference data are publicly available from the National Ecological Observatory Network (NEON) \cite{NEON}. The multispectral imagery used in this study is publicly available through the USDA National Agriculture Imagery Program (NAIP) \cite{NAIP}.
